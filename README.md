# doximity_scrapy
Doximity scraper

## Test scraper/parser

1. Activate your conda environment:

`conda activate uatu`

2. Create a `logs` folder in the repo directory if doesn't exist:

`mkdir logs`

3. Run scraper:

`python -m src.scraper`

(Note that at the moment the code is not written to scrape the whole Doximity website/graph).

4. Run parser:

`python -m src.parser`
